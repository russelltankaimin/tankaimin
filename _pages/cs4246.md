## Lecture 1  
#### Assumption  
- Agent in task Environment  

#### Definition  
- States in an environment, with initial state  
- *Actions* available in a state  
- *Effects* of applying an action  
- *Goal* to test to see if objective is met  

So what we are trying to do is to start from initial state, find action sequence whose effects (resulting states) lead to the goal state.  

#### Classical Planning (Lecture Vid)  
The setup for this planning problem is that the *Environment* is **DISCRETE, DETERMINISTIC, STATIC, FULLY OBSERVABLE**  

- Problem Forumlation - PDDL (Planning Domain Definition Language) from STRIPS  
- Search For a Solution (plan) - via search and satisfiability  
- Heuristics for efficiency  

##### PDDL  
- Logic based, lifted propositional representation (to restricted first order logic)  
- Factored representation (rep state of the world as state vars and fluents)  
- Fluent : an aspect of the world that changes with time  

##### STATE  
- A Conjunction of ground atomic fluents  
    - Ground Atomic means there is a single predicate, with only constant arguments, function free  
    - E.g Hungry ∧ Sleepy, so sleepy and hungry are ground atomic  
    - E.g New(Plane_{1}) ∧ Safe(Plane_{1}), so New/Safe(Plane_{1}) are ground atomic as Plane_{1} is a constant argument  
- Goal State  
    - A goal `g` is a partially specified state, as a conjunction of literals  
    - A state `S` satisfies a goal `g` if `S` contains all the literals in `g`  
    - Hungry ∧ Sleepy ∧ Bored satisfies the goal Hungry ∧ Bored  
    - At(Cargo, SFO) satisfies At(c, SFO) through the substitution c/Cargo  

##### ACTION SCHEMA  
- Defines a family of ground actions  
    - All vars assumed to be universally quantified  
    - Lifts prop. logic to restricted subset of FOL  
    - Preconditions : Conjunctions of literals which defines the state in which action can be executed  
    - Effects : Conjunctions of literals defining the result of executing the action  
    - E.g. Action(Fly,p, from, to)  
    - PRECOND : At(p, from) ∧ Plane(p) ∧ Airport(from) ∧ Airport(to)  
    - EFFECT : ¬At(p, from) ∧ At(p, to)
