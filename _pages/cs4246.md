## Lecture 1  
#### Assumption  
- Agent in task Environment  

#### Definition  
- States in an environment, with initial state  
- *Actions* available in a state  
- *Effects* of applying an action  
- *Goal* to test to see if objective is met  

So what we are trying to do is to start from initial state, find action sequence whose effects (resulting states) lead to the goal state.  

#### Classical Planning (Lecture Vid)  
The setup for this planning problem is that the *Environment* is **DISCRETE, DETERMINISTIC, STATIC, FULLY OBSERVABLE**
